# 📊 Retail Sales & Profitability Dashboard

An interactive Power BI dashboard designed to analyse sales performance, profitability, product categories, and regional trends. This project transforms raw financial data into meaningful business insights to support data-driven decision-making.

## 📌 Project Overview

The objective of this project is to evaluate business performance using sales and financial data. The dashboard provides insights into revenue, profit margins, product performance, and customer segments to help identify growth opportunities and improve profitability.

## 🎯 Business Objectives

- Analyse overall sales and profitability.
- Identify the most profitable products and categories.
- Evaluate regional and country-level performance.
- Understand monthly sales and profit trends.
- Compare revenue across customer segments.
- Generate actionable recommendations for business growth.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Interactive dashboards and data visualisation
- **Power Query** — Data cleaning and transformation
- **DAX** — Measures and KPI calculations
- **Microsoft Excel / CSV** — Dataset preparation and exploration

## 📂 Dataset

This project uses Microsoft's Financial Sample dataset, which contains financial data across products, countries, segments, and time periods.

**Dataset source:** [Microsoft Power BI Financial Sample](https://learn.microsoft.com/en-us/power-bi/create-reports/sample-financial-download)

The dataset includes fields such as:

- Segment
- Country
- Product
- Discount Band
- Units Sold
- Manufacturing Price
- Sale Price
- Gross Sales
- Discounts
- Sales
- COGS
- Profit
- Date

## 📊 Key Performance Indicators (KPIs)

The dashboard can include the following measures:

- **Total Sales:** Total revenue generated.
- **Total Profit:** Total profit recorded in the dataset.
- **Profit Margin:** Profit divided by Sales, multiplied by 100.
- **Total Units Sold:** Total quantity of products sold.
- **Sales Growth:** Percentage change in sales compared with the previous period.

*Note: KPI values and business findings will be added after the dashboard is built and the data has been validated.*

## 🔍 Project Workflow

1. Download the Financial Sample dataset.
2. Import the dataset into Power BI.
3. Inspect and clean the data using Power Query.
4. Validate data types, dates, missing values, and financial fields.
5. Create calculated measures using DAX.
6. Design interactive charts, KPI cards, and slicers.
7. Analyse the results and document key findings.
8. Publish project files and dashboard screenshots to GitHub.
